# Jarurat Care — Patient Records Dashboard

Simple React app demonstrating fetching patient data, search, responsive UI, and modal details.

## Features
- Landing header with navigation
- Patients page: fetches patient data, shows responsive card grid
- Search bar to filter by name
- View details modal per patient
- Add new patient (local only)
- Loading & error states
- Built with React + Vite + Tailwind CSS
